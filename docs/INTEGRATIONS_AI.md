# План по интеграциям и ИИ (MVP)

## Git и артефакты кода

- OpenAPI → карта эндпоинтов, диаграммы последовательностей
- Схема БД → генерация ERD (через интроспекцию или файлы миграций)
- IaC (Terraform) → граф топологии инфраструктуры (первым AWS)
- Webhook’и PR → вычисление диффов → предложения изменений в диаграммах

## Модель синхронизации

- Декларативная спецификация → графовая модель → механизм раскладки → холст
- Двунаправленность: ручные правки помечаются; предлагаем git‑патч или локальное переопределение
- Диффы перед применением обязательны к обзору; история изменений и откат

## Функции ИИ

- Черновик по промпту/спецификации; нормализация/чистка лайаута; авто‑группировка
- Пояснение дельт диаграмм относительно PR; генерация легенд/описаний
- Гарантии: валидаторы, понимающие схему; ограниченные действия; таймауты

## Технические заметки

- Воркеры для парсинга/сборки графа; очереди для тяжёлых задач
- Абстракции провайдеров SCM (GitHub/GitLab/Bitbucket)
- Парсеры OpenAPI/SQL; граф Terraform (hcl) → ресурсный DAG
