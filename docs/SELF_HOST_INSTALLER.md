# Инсталлятор для Self‑Host (дизайн)

## Цели
- Docker Compose (single‑node) и Helm‑чарт (Kubernetes)
- Postgres, объектное хранилище (совместимое с S3), опционально Redis

## Процесс установки
- Один скрипт установки; конфигурация через env/values.yaml; проверки здоровья
- Бутстрап админа; мастер настройки SSO; активация лицензии (поддержка офлайн)
- Скрипты бэкапов/восстановления; наблюдаемость (логи/метрики/трейсы)

## Обновления в изолированных контурах
- Подписанные релизы; офлайн‑лиценз‑сервер
- Апгрейд через переносимые носители; проверка контрольных сумм; откаты

## Безопасность по умолчанию
- Жёсткие заголовки/CSP; TLS‑терминация; рекомендации по ротации секретов
- Наименьшие привилегии для сервис‑аккаунтов; сетевые политики в K8s
