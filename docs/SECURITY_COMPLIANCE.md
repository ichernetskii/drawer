# Дорожная карта по безопасности и соответствию

## Базис (MVP)

- Аутентификация: OIDC/SAML SSO; SCIM (базовый) для провижининга
- Журналы аудита: входы, доступ к доскам, шеринги, экспорты, админ‑действия
- Безопасность данных: «в покое» (AES‑256) и «в пути» (TLS1.2+); хранилище секретов
- Self‑host: манифесты Docker/K8s, конфигурация как код, бэкапы и ротация ключей

## Управление

- Роли/права, защищённые пространства, владение досками и передача
- Водяные знаки и ссылки только для чтения; ограничения на экспорт
- Потоки согласования для публичного шаринга и меж‑воркспейсных переносов

## Программа соответствия

- SOC 2 Type I → Type II (6–12 мес), ISO 27001 (опционально)
- Управление рисками: оценка вендоров, пентесты, управление уязвимостями (SLA)
- DPA, резидентность данных (EU/US), прозрачность суб‑процессоров

## Изолированный контур (дизайн)

- Офлайн‑лиценз‑сервер, подписанные релизы, дифф‑обновления
- Экспорт аудита и импорт политик через съёмные носители

## Наблюдаемость и реагирование

- Централизованные логи, интеграция с SIEM, алерты аномалий
- Планы реагирования на инциденты безопасности; SLA уведомлений о нарушениях
