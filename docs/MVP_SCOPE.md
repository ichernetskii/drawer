# MVP‑объём (90–120 дней)

## Результаты

- Команды могут импортировать существующие доски, сотрудничать в реальном времени/офлайн и разворачивать защищённый self‑host.
- Диаграммы создаются/рефакторятся ИИ и синхронизируются с артефактами кода (OpenAPI/БД/IaC) с обозреваемыми диффами.

## В объёме

- Холст в реальном времени с производительностью на больших досках (виртуализированный рендеринг, ленивые слои)
- Офлайн‑первая коллаборация на CRDT; бесконфликтные слияния
- Импорт: Miro (.rtb) и draw.io (.drawio); Экспорт: SVG, PDF
- Self‑host beta: Docker Compose + Helm chart; OIDC/SAML SSO; базовые журналы аудита
- Интеграции с Git:
    - OpenAPI → карта эндпоинтов, последовательности
    - ERD из схемы БД (SQL‑интроспекция или миграции)
    - IaC (Terraform) → топология инфраструктуры (базовые ресурсы)
    - Один клик синхронизации + просмотр диффов PR
- Функции ИИ (с ограничениями):
    - Черновик диаграммы по тексту/спецификации
    - Рефакторинг/нормализация лайаута
    - Дифф PR → предложение изменений диаграммы

## Вне объёма (MVP)

- Полные DLP‑политики, водяные знаки, продвинутое управление (после MVP)
- Обновления в изолированных контурах (пока дизайн)
- Полные пакеты нотаций (BPMN/ArchiMate/UML) — только базовые фигуры

## Критерии приёмки

- Импорт ≥95% по распространённым примитивам Miro/draw.io
- 100 объектов без потери плавности пан/зум 60fps на современных ноутбуках
- Self‑host установка <10 минут; вход через SSO с Okta/Azure AD
- Git‑синхронизация: е2е‑демо с OpenAPI + Terraform; диффы для ревью
- Операции ИИ <10 секунд с откатом; без разрушительных авто‑изменений

## Риски и меры

- Производительность на гигантских досках → виртуализация, квадродеревья, вынос в воркеры
- Качество ИИ → детерминированные преобразования, эталоны, человек в контуре
- Паритет импорта → приоритет топ‑20 примитивов, итеративные «золотые» тесты
